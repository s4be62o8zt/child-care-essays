# 担心甲状腺手术留下“自杀式”疤痕？医生有高招，伤口能“隐身”

甲状腺肿瘤是

目前人群中最常见的肿瘤之一

要切除肿瘤

常规开放手术是主流治疗方法

但会留下一道**“自杀式”的疤痕**

这常让患者望而却步

**有没有一种方法**

**既能够根治甲状腺肿瘤**

**又能让伤口小而“隐身”**

日前，温州市中西医结合医院肿瘤血液病科为一位年轻甲状腺癌女性患者顺利完成**经乳腔镜甲状腺肿瘤切除术**。术后脖子上没有留下任何疤痕。

**手术切口“藏”到乳晕**

数月前，20多岁的年轻姑娘小王不幸查出罹患了甲状腺乳头状癌。医生建议她马上接受手术治疗。

然而面对手术，小王无比忧虑，不仅是担心自己的健康，还害怕**手术会在脖子上留下一道长长的疤痕**，不知以后该怎么面对别人的目光。

听说温州市中西医结合医院已经开展了多年的腔镜甲状腺手术，这种手术方式**创口隐蔽、创伤小**且**安全性高**，同时**费用与开放手术相近**后，她毅然选择了经乳腔镜甲状腺肿瘤切除术。

**肿瘤血液病科主治医师陈伟克从乳晕区的隐蔽小切口入路****，完整切除病灶，****实现颈部“无痕”。**

术后，小王发现自己的手术创口小到几乎找不到，终于如释重负，术后三天就顺利出院了。

**哪些甲状腺结节需要手术**

甲状腺结节可以用过B超、颈部CT、查体等方式发现。

如果B超检查提示**结节等级在IV级及以上**，或**合并颈部淋巴结异常增大**，可通过**超声引导下甲状腺结节穿刺术明确结节性质。**

一般**临床或穿刺疑似恶性肿瘤**的患者，都可以选择腔镜甲状腺手术。

如果甲状腺结节考虑是良性肿瘤，但是肿瘤较大，对患者的吞咽功能或颈部外观造成影响的患者，也可以通过手术治疗解决问题。

**腔镜甲状腺手术**

**能“切干净”吗**

近年来接受甲状腺手术的患者比例逐年增加，同时人们对美容的需求越来越高。

目前，温州温州市中西医结合医院除了常规开放手术外，还开展**腔镜甲状腺手术（经腋窝、经乳晕、经口），**以及**甲状腺肿瘤微波消融术**，为众多患者根除肿瘤的同时，又兼顾了“美”的需求。

相较于传统手术，**腔镜微创手术避免了颈部的手术疤痕**，通过有限的组织创伤，极大地减少病人心理创伤。

颈部没有疤痕，病人可以早期颈部活动，**显著减少疤痕形成及粘连可能造成的颈部异物感和吞咽不适感。**

另外重要的是，在腔镜放大视野中，解剖层次更加清晰，手术操作更为精细。

**该术式在保证手术质量的前提下，实现微创、无痕，提高病人生活质量。**

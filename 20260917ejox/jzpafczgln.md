# 【健康科普】夏季防暑小贴士

> 更新时间：2026-09-17 (UTC+8)

**中暑不容忽视！尤其需警惕这两类危险信号：  **

一是先兆或轻症中暑：若出现头晕恶心、心跳加快、大量出汗等症状，需立即处理；  

二是热射病：表现为高烧（＞40℃）、皮肤干热发红、剧烈头晕甚至抽搐昏迷，可能危及生命，需第一时间拨打120！  

**关键预防措施**

1. 主动补水，别等口渴：少量多次饮用白开水最佳，出汗较多时可适当补充淡盐水或吃些咸菜，但饮料无法完全替代水。  

2. 避开高温时段：上午10点至下午4点是一天中最热的时候，尽量减少外出，待在室内或阴凉处。如需外出，建议佩戴宽檐帽、太阳镜，选择轻薄透气的浅色衣物。  

3. 保持室内凉爽：天气炎热时需开窗通风，或使用风扇、空调。建议将空调温度设置在26-28℃，既舒适又节能。高温高湿天气下，空调的降温效果比风扇更明显。  

4. 关注特殊人群：老年人、儿童、慢性病患者（如心脏病、高血压、糖尿病患者）、肥胖人群、孕产妇等对高温更敏感，需格外注意。此外，正在服用感冒药、利尿剂、精神类药物等可能影响出汗或体温调节的人群，建议提前咨询医生。  

5. 避免过度劳累：高温环境下应避免剧烈运动或长时间劳作，运动或工作需循序渐进，中途多到阴凉处休息。  

**万一有人中暑（热射病），这样做！**

1. 迅速转移：立即将患者移至阴凉通风处；  

2. 快速降温：用凉水（非冰水）喷洒身体，或用湿毛巾擦拭全身并扇风，重点擦拭颈部、腋窝、大腿根等部位；  

3. 补充水分：若患者意识清醒且能饮水，可给予淡盐水或运动饮料；若已昏迷则不要强行喂水；  

4. 及时求助：尤其当患者出现高热、昏迷、抽搐等症状时，需在等待救护车的过程中持续进行降温，并立即拨打120。  

防暑口诀请牢记：多喝温水补水分，避开烈日少暴晒，室内通风要保持，特殊人群多留意，不适及时降体温。

**健康科普：预防中暑远胜急救，做好防护才能安心度夏！**

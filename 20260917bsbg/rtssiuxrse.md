# 孕妇怀孕中期可以吃韭菜饺子吗

> 更新时间：2026-09-17 (UTC+8)

韭菜是生活中很常见的蔬菜，不仅能用作调料，在北方地区还可以用来包韭菜馅饺子。韭菜带有的特殊香味也让怀孕中期的孕妇特别有胃口，既想吃又担心温热性质的韭菜会导致胎儿流产。那么，孕妇怀孕中期可以吃韭菜饺子吗?
孕妇怀孕中期可以吃韭菜饺子吗
　　孕妇可以适量吃一些韭菜饺子，有些说法称韭菜有加强子宫收缩的作用，孕妇吃会增加流产风险，韭菜中丰富的维生素、挥发性精油、硫化物等成份都具有防止肠癌等养生保健功效。另外韭菜饺子与猪肉类食品互相搭配吃起来非常营养。

　　因为在孕期胎儿逐渐长大，增大的子宫可压迫孕妇的直肠，使得孕妇出现便秘的症状。韭菜饺子中的韭菜含有大量的粗纤维，可以有效促进胃肠蠕动，缓解孕妇便秘等不适。

　　至于吃韭菜引发宫缩导致流产，这也是根据个人体质来进行判断的，并不是说所有孕妇吃韭菜就会导致流产。因此，孕妈们适宜的吃还是可以的，但不能一次吃太多韭菜，否则会刺激肠胃，引起腹泻。所以，最好控制在一顿100克到200克。

　　不过孕妇吃饺子需注意，饺子虽然好吃且营养，但孕妇吃饺子不宜过量食用，而且要选择孕妇能吃的饺子馅。过量食用容易消化不适，引起腹胀、胃不适等症状。孕期饮食关键在于不要偏食、不要过量，饮食尽可能广泛多样化，多吃高蛋白优质蛋白食物，多吃新鲜的蔬菜水果，这样营养才均衡。
孕妇吃的韭菜饺子怎么做
　　做法一

　　食材：饺子皮、肉馅、生抽、盐、糖、韭菜

　　1. 按比例准备好食材，加入调味料。

　　2. 用手抓或轻揉，使馅料味道充分融合，这样的馅料更加入味，口感极佳。

　　3. 包法一般个有千秋，本人有点强迫症，必须每个棱角分明。

　　做法二

　　食材：猪肉、韭菜、饺子面、生抽、葱段、姜末、胡椒粉、凉水

　　1. 将猪肉剁碎。

　　2. 在碗中放入切碎的韭菜，再放入葱段、姜末以及调味料生抽5克、胡椒粉3克之后，搅拌均匀。

　　3. 饺子面先搓成长条，然后捏成一个个的剂子。

　　4. 将一个个剂子搓圆后压扁，擀成饺子皮。

　　5. 放入韭菜猪肉馅，包成饺子。

　　做法三

　　食材：韭菜、面粉、盐、鸡蛋、蚝油、胡椒粉、味精、白糖

　　1. 韭菜清洗干净，沥干水分。

　　2. 鸡蛋打散倒入热油锅，划散开来，放凉。

　　3. 沥干水分的韭菜切碎放入锅里。

　　4. 放调料把鸡蛋韭菜拌匀入味。

　　5. 面粉加适量水加点盐，揉面光盆光手光，盖盖子醒面半个小时左右，中途再揉两次面团这样更光滑。

　　6. 醒好的面团取一些出来，擀面皮包成自己喜欢的样子。
